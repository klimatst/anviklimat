# Запуск КлимаЭко в XAMPP без установщика

В архиве находится готовый PHP-сайт и конфигурация для локального XAMPP. Отдельный мастер установки не запускается: сайт открывается по обычному адресу, а при первом запросе создаёт базу `klimaeco`, таблицы, категории, формулы, страницы прайсов и каталог Hisense.

## 1. Запуск на этом компьютере

1. Установите XAMPP с PHP 8.1+ и MySQL/MariaDB.
2. В XAMPP Control Panel запустите **Apache** и **MySQL**.
3. Распакуйте ZIP прямо в `C:\xampp\htdocs\klimaeco`. Файл `index.php` должен лежать непосредственно в этой папке.
4. Откройте `http://localhost/klimaeco/`.

При первом открытии сайт создаст базу `klimaeco`, если у MySQL-пользователя есть право создавать базы. Данные с диска и существующие таблицы не удаляются. Если база уже заполнена, сайт использует её и только создаёт недостающие таблицы.

В комплекте настройки `app/config.php` указаны стандартные локальные реквизиты XAMPP: сервер `localhost`, порт `3306`, пользователь `root`, пустой пароль. Если у вас задан пароль MySQL или другой пользователь, измените значения в `app/config.php` до открытия сайта.

## 2. Импорт базы вручную через phpMyAdmin

Полный SQL-файл находится в архиве по пути `database/klimaeco.sql`. Его также можно скачать отдельно со страницы сайта «Архивы и загрузки».

1. Откройте `http://localhost/phpmyadmin/`.
2. Создайте пустую базу `klimaeco` с кодировкой `utf8mb4_unicode_ci` либо выберите пустую существующую базу.
3. Откройте вкладку **Импорт**, выберите `database/klimaeco.sql` и запустите импорт.
4. Проверьте, что `app/config.php` содержит те же имя базы, логин и пароль.
5. Откройте `http://localhost/klimaeco/`.

SQL-файл включает структуру таблиц, начальные настройки, категории, формулы, страницы прайсов и 241 модель Hisense. Импортируйте его только в пустую базу: повторный импорт в заполненную базу может встретить дубли ключей. Резервную копию рабочей базы можно создать через `BACKUP-LOCAL.cmd`.

## 3. Вход администратора

Начальные данные для локальной базы:

- Логин: `admin`
- Пароль: `admin`

Сразу после входа откройте **Настройки сайта** и смените пароль на собственный. Не оставляйте этот пароль при открытии сайта другим устройствам в локальной сети.

## 4. Запуск встроенным сервером PHP

Можно запустить `START-LOCAL.cmd` вместо Apache. Скрипт проверит PHP, попробует запустить MariaDB и предложит открыть сайт только на этом компьютере или в локальной сети. Адрес локальной сети будет показан в консоли. Устройства должны быть в одной сети; если Windows Firewall задаст вопрос, разрешите подключение для частной сети.

Для остановки сервера нажмите `Ctrl+C` в его окне. Не используйте встроенный сервер PHP для публичного сайта.

## 5. Перенос данных из Anvil

Начальная SQL-база содержит структуру и исходный каталог, но не ваши персональные записи Anvil. Чтобы перенести их отдельно:

1. Откройте в Anvil модуль **Резервные копии** и скачайте **Переносимый экспорт для XAMPP**.
2. Сначала откройте локальный сайт один раз, чтобы он создал базу.
3. Скопируйте экспорт в `storage/imports/` и назовите его `anvil-export.json.gz`.
4. Запустите `IMPORT-ANVIL.cmd`.

Экспорт содержит данные заявок и проектов. Храните его на доверенном компьютере и удалите файл из `storage/imports` после проверки импорта. Пароли, активные сессии и ключи API Anvil не переносятся.

## 6. Доступ из локальной сети через Apache

После запуска Apache сайт будет доступен с других устройств по IPv4-адресу компьютера, например `http://192.168.1.25/klimaeco/`. Узнайте адрес командой `ipconfig`. Разрешите Apache в брандмауэре Windows для частной сети. Устройства должны быть подключены к тому же Wi-Fi/LAN.

Ссылки на сайте строятся с учётом адреса и папки проекта, поэтому отдельная настройка домена для локальной сети не требуется. Если вы задали `base_url` вручную в `app/config.php`, очистите его, чтобы включить автоматическое определение адреса.

## 7. Установка на PHP-хостинг

Загрузите файлы в каталог сайта и отредактируйте `app/config.php`: задайте выданные хостингом сервер, порт, имя базы, логин и пароль. В панели хостинга создайте пустую базу и импортируйте `database/klimaeco.sql` либо откройте сайт и используйте пользователя базы с правом `CREATE DATABASE`. Смените начальный пароль администратора сразу после входа. Не оставляйте SQL-дамп и экспорт Anvil в публично доступном каталоге.

## Если сайт не открывается

- **Ошибка подключения к MySQL:** убедитесь, что MySQL запущен; проверьте реквизиты в `app/config.php` и порт `3306`.
- **Не удаётся создать базу:** создайте пустую `klimaeco` в phpMyAdmin либо импортируйте `database/klimaeco.sql` вручную.
- **Не найден `pdo_mysql`:** включите расширение в `php.ini` выбранного XAMPP PHP и перезапустите Apache.
- **Apache показывает Not Found:** проверьте, что `index.php` лежит прямо в `C:\xampp\htdocs\klimaeco`, затем откройте `http://localhost/klimaeco/`.
- **Экспорт Anvil не загружается:** проверьте имя `anvil-export.json.gz` и папку `storage/imports`.

## Резервные копии и обновления

- Запустите `BACKUP-LOCAL.cmd` перед обновлением; SQL-файл будет записан в закрытую папку `storage/backups/`.
- Не заменяйте `app/config.php`, `storage/uploads/`, `storage/imports/` и `storage/backups/` при обновлении существующей установки.
- После обновления запустите сайт и проверьте каталог, админку и формы. Схема дополняется безопасными `CREATE TABLE IF NOT EXISTS` без удаления записей.

## О переносе из Anvil

Мигратор сохраняет исходные записи 44 таблиц и переносит основные данные в рабочие разделы PHP: категории, бренды, товары, формулы, CMS-страницы, новости, галерею, проекты, помещения, системы, расчёты и сметы. Контакты заказчика и адрес объекта видны в карточке проекта; полные CRM-записи, строки смет, компоненты и связи систем сохраняются в таблице `anvil_export_rows`. Модели данных PHP и Anvil различаются, поэтому перенос не копирует исполняемый код и настройки подключённых внешних сервисов.
