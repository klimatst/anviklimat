# КлимаЭко: автономная версия для XAMPP и PHP-хостинга

Это локально устанавливаемый PHP/MySQL-вариант проекта. В нём есть публичные страницы, каталог, отдельная админ-панель, калькуляторы, редактор страниц, заявки, галерея и Engineering OS. Внешний вид переведён на палитру Anvil-версии: тёмный графитовый фон и бирюзовый акцент.

Инструкция для Windows/XAMPP находится в [`INSTALL_XAMPP_RU.md`](INSTALL_XAMPP_RU.md). Архив выпуска собирает `tools/build-xampp-release.py` из корня репозитория.

## Что входит

- Каталог с категориями, брендами, товарами, ценами, характеристиками и изображениями.
- Страницы, новости, галерея и формы заявок.
- Независимые калькуляторы кондиционирования, вентиляции, монтажа и линейка холодильщика.
- Engineering OS с проектами, помещениями, системами, расчётами и сметами.
- Админ-панель с отдельными разделами контента, каталога, заявок, тарифов и формул.
- Установщик с выбором MySQL/MariaDB, адреса сайта и учётной записи администратора.
- SQL-резервное копирование локальной базы и переносимый экспорт из Anvil.

Первичная база содержит исходные 89 категорий, формулы и страницы прайсов, а также 241 модель Hisense из доступного в репозитории снимка. Демонстрационные товары выключены по умолчанию.

## Перенос рабочей базы Anvil

В админке Anvil откройте «Резервные копии» и скачайте «Переносимый экспорт для XAMPP». На локальном сайте сначала завершите установку, затем поместите файл `klimaeco-anvil-export-*.json.gz` в `storage/imports/` и переименуйте его в `anvil-export.json.gz`. Запустите `IMPORT-ANVIL.cmd`.

Экспорт включает 44 таблицы приложения и значения медиа-полей. Данные сохраняются в защищённой таблице `anvil_export_rows`; категории, бренды, товары, формулы, CMS-страницы, новости, галерея, проекты, помещения, системы, расчёты и сметы также сопоставляются с рабочими разделами PHP-версии. В админке можно отредактировать исходную JSON-запись и применить зеркало повторно. Полные CRM-поля, строки смет, компоненты и системные записи остаются в зеркале, чтобы сохранить поля, для которых PHP использует другую модель. Пароли, активные сессии и ключи API не переносятся. Персональные данные заявок и проектов остаются в файле экспорта и локальной базе, поэтому храните архив отдельно и удалите его после проверки переноса.

Экспорт сейчас ограничен 20 МБ в сжатом виде, 40 МБ после распаковки и 20 000 строк. Если рабочая база больше, установщик сообщит об этом: пакетный экспорт по частям ещё не поддерживается. Закрытые секреты Anvil, подключения сторонних сервисов, код Python и права доступа Anvil не превращаются автоматически в PHP-конфигурацию.

Перенос сохраняет схему и данные таблиц, но не делает две платформы идентичными на уровне кода. CMS-модули, AI-провайдеры, авторизация, интеграции и часть инженерных процессов имеют разную модель на Anvil и PHP. Для полей, которые PHP пока не показывает отдельными формами, доступны исходные записи в `anvil_export_rows`.

## Безопасность и резервные копии

- Пароль администратора хранится как парольный хеш.
- Настройки базы находятся в `app/config.php`; каталог `app/` закрыт веб-доступом.
- SQL-копии и экспортируемые данные хранятся в закрытых подпапках `storage/`.
- Для локального встроенного PHP-сервера `router.php` закрывает конфигурацию, исходные JSON, резервные копии и служебные скрипты.
- Не публикуйте `app/config.php`, файлы экспорта и резервные копии в GitHub или в открытом веб-каталоге.
- Перед обновлением запустите `BACKUP-LOCAL.cmd`.

## Технические требования

- PHP 8.1+; расширения PDO, PDO MySQL и zlib.
- MySQL или MariaDB с `utf8mb4`.
- Apache для обычного веб-хостинга. Для Apache должны быть включены правила `.htaccess`.
- На локальном сервере Windows потребуется PHP CLI с `pdo_mysql` и PowerShell для определения LAN-адреса.

Папки `storage/uploads`, `storage/imports` и `storage/backups` должны быть доступны PHP для записи. Не используйте XAMPP с пустым паролем `root` на внешнем сервере.
