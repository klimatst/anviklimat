# ЭКО-КЛИМАТ — версия для PHP-хостинга

Это отдельная переносимая версия сайта для Beget и обычного PHP-хостинга. Она устанавливается через браузер, работает на PHP и MySQL/MariaDB, не требует Composer, SSH или ручного запуска SQL-файлов. Исходный проект Anvil остаётся отдельным и не меняется.

## Что входит

- Адаптивные главная страница и меню в графитовой и медной палитре.
- Каталог с категориями и подкатегориями, брендами, карточками товаров и характеристиками.
- Новости, обычные страницы сайта и простой редактор HTML-разметки с фильтрацией содержимого.
- Галерея работ: фотографии можно загрузить на сайт или подключить по внешнему HTTPS-адресу.
- Формы заявки на консультацию и сервис, список обращений в админ-панели.
- Предварительный калькулятор нагрузки для кондиционирования.
- Три редактируемые CMS-страницы прайсов: монтаж кондиционеров, VRV / VRF и вентиляции; недостающие страницы добавляются в уже установленную локальную базу без перезаписи страниц, изменённых администратором.
- Настройки названия, телефона, электронной почты, адреса и краткого описания.
- Браузерный установщик, хеширование пароля администратора, CSRF-защита, ограничение попыток входа и блокировка повторного запуска установщика после установки.

Установщик импортирует 89 категорий, 11 формул и три прайс-страницы из комплекта проекта. По умолчанию включён импорт **241 реальной строки каталога Hisense** из `server_code/HisenseLovableCatalogData.py`: артикулы, цены, серии, характеристики и категории сверяются с исходным репозиторием. Доступные семейства используют фото-URL из `HisenseCatalogSync.py`; для части аксессуаров и блоков пока используются локальные тематические изображения-заглушки. По желанию отдельно можно добавить 10 брендов и 30 явно помеченных тестовых товаров.

## Состав комплекта

- `index.php` — публичный сайт.
- `admin/` — административная панель.
- `install/` — мастер первоначальной установки.
- `app/` — подключение к базе и серверная логика.
- `assets/` — оформление, скрипты и изображения.
- `data/` — исходные данные для первичного импорта; Apache закрывает папку правилами `.htaccess`.
- `storage/uploads/` — загруженные фотографии.

## Быстрый запуск на Windows

1. Распакуйте репозиторий или откройте папку `shared_hosting_php` внутри уже скачанного проекта.
2. Запустите `START-LOCAL.cmd`. Скрипт ищет PHP в `C:\\xampp\\php\\php.exe`, `C:\\tools\\xampp\\php\\php.exe` или в `PATH`; при найденном XAMPP пытается запустить MariaDB.
3. Откроется `http://127.0.0.1:4173/install/` при первом запуске или главная страница после установки.
4. В мастере задайте имя базы, пользователя и пароль. В XAMPP по умолчанию часто используется пользователь `root` без пароля; это локальная настройка, не используйте её на публичном сервере. Если у пользователя есть право создания баз, установщик создаст базу автоматически; иначе сначала создайте её через phpMyAdmin.
5. Придумайте пароль администратора длиной не менее 10 символов. Не используйте пароль `admin` или другие стандартные пароли.

Сервер привязан к `127.0.0.1` и не публикует сайт в локальную сеть. Для остановки сервера нажмите `Ctrl+C` в окне запуска. Если порт 4173 занят, закройте старый процесс или освободите порт. После установки удалите папку `install` перед публичным размещением.

## Требования

- PHP 8.1 или новее.
- PHP-расширения PDO и PDO MySQL.
- MySQL или MariaDB, кодировка `utf8mb4`.
- Для запуска через `START-LOCAL.cmd`: PHP CLI с `pdo_mysql`; при использовании XAMPP — его MariaDB.
- Для размещения на обычном хостинге: Apache, который поддерживает `.htaccess` (типичная настройка shared-хостинга).
- Свободное место для фотографий и резервных копий.

На публичном сайте отключите отображение PHP-ошибок посетителям. При неполадках проверьте журнал ошибок PHP в панели хостинга.

## Перенос данных и ограничения

Данные Anvil не изменяются, а закрытые таблицы опубликованного Anvil-сайта не были доступны для надёжного экспорта. В пакет перенесены категории, расчётные формулы, прайс-страницы и 241 запись Hisense из исходного кода репозитория; это не экспорт приватной базы Anvil. Реальные новости, проекты, заявки, пользователи, другие бренды и закрытые записи автоматически не переносятся. Для уже установленной PHP-версии запустите `IMPORT-HISENSE.cmd`: импорт добавит отсутствующие записи и заполнит пустые поля/изображения-заглушки, не перезаписывая непустые поля, отредактированные администратором.

PHP-версия не является побайтной копией Anvil-проекта: Anvil-авторизация, AI-оператор, интеграции Telegram/соцсетей и полноценный конструктор инженерных проектов в неё не входят. Для этих функций нужен отдельный перенос логики и данных. Эта сборка предназначена как лёгкий CMS-сайт каталога и презентации для обычного хостинга.

Фотографии в `assets/images/` взяты из предыдущего комплекта проекта; авторство и лицензии указаны в `assets/images/ATTRIBUTION.txt`.


## Резервная копия локальной базы

Перед дальнейшими изменениями запустите `BACKUP-LOCAL.cmd`. Он экспортирует структуру и содержимое таблиц из базы, указанной в `app/config.php`, в новый SQL-файл в `storage/backups/`. Таблицы не изменяются. Экспорт запускается только из командной строки, а прямой HTTP-доступ к скрипту и папке резервных копий закрыт. Сохраните копию также вне компьютера и не публикуйте её в GitHub: в базе могут быть персональные данные заявок.
