# Полная установка КлимаЭко в XAMPP

## 1. Подготовьте XAMPP

1. Установите XAMPP с PHP 8.1 или новее и MariaDB/MySQL.
2. Откройте XAMPP Control Panel и запустите **Apache** и **MySQL**.
3. Проверьте, что включены расширения PHP `pdo_mysql` и `zlib`. В стандартном XAMPP они включены. Если установщик отметит расширение красным, откройте `php.ini`, включите соответствующий `extension=...`, сохраните файл и перезапустите Apache.

## 2. Распакуйте архив

Распакуйте ZIP целиком в `C:\xampp\htdocs\klimaeco`. В корне папки должны находиться `index.php`, `install`, `admin`, `app`, `assets`, `data` и `storage`.

Проверьте путь: установщик должен находиться именно в `C:\xampp\htdocs\klimaeco\install\index.php`. Если внутри `klimaeco` появилась ещё одна папка `KlimaEco`, значит использован старый архив со вложенным корнем; распакуйте новый архив с заменой файлов или переместите содержимое внутренней папки на уровень `klimaeco`.

Если XAMPP установлен в другом месте, используйте каталог `htdocs` именно этой установки. Не распаковывайте проект в `xampp\mysql\data`.

## 3. Создайте базу данных

Откройте `http://localhost/phpmyadmin/`.

- Можно заранее создать пустую базу `klimaeco` с кодировкой `utf8mb4_unicode_ci`.
- Либо пропустить этот шаг: установщик попробует создать базу сам, если MySQL-пользователю разрешена операция `CREATE DATABASE`.

Если включена авторизация MySQL, задайте имя пользователя и пароль, которым разрешён доступ именно к этой базе. Установщик никогда не удаляет существующие таблицы.

## 4. Пройдите мастер установки

Откройте `http://localhost/klimaeco/install/` и заполните поля:

- **Хост базы:** `127.0.0.1` или `localhost`.
- **Порт:** обычно `3306`.
- **База данных:** `klimaeco` или имя предварительно созданной базы.
- **Пользователь и пароль MySQL:** реквизиты из phpMyAdmin/XAMPP.
- **Адрес сайта:** `http://localhost/klimaeco`.
- **Название сайта:** «КлимаЭко».
- **Логин и пароль администратора:** задайте собственный пароль длиной не менее 10 символов.

Оставьте «Демонстрационные товары» выключенными. Импорт Hisense включает исходный снимок из репозитория и может быть отключён, если этот каталог не нужен. Нажмите **«Проверить базу и установить сайт»**.

После сообщения об успешной установке откройте сайт и админ-панель через кнопку установщика или по адресам `http://localhost/klimaeco/` и `http://localhost/klimaeco/admin/`. Удалите папку `install` после завершения настройки.

## 5. Перенесите данные из Anvil

1. В Anvil войдите администратором и откройте модуль «Резервные копии».
2. Нажмите **«Скачать переносимый экспорт для XAMPP»**.
3. Скопируйте скачанный файл в `C:\xampp\htdocs\klimaeco\storage\imports\`.
4. Переименуйте его в `anvil-export.json.gz`.
5. Запустите `IMPORT-ANVIL.cmd` из проводника.
6. После сообщения `Перенос Anvil завершён` удалите файл из `storage\imports` и проверьте каталог, страницы и галерею.

Экспорт содержит личные данные заявок и проектов. Храните его только на доверенном компьютере. Пароли пользователей, действующие сессии и ключи API не переносятся; учётную запись PHP-администратора задают отдельно на шаге установки. После импорта администратор может изменить запись в разделе «Данные Anvil» и применить зеркало повторно без повторной загрузки исходного файла.

При превышении лимита 20 МБ сжатого файла или 40 МБ исходных данных импорт остановится с сообщением. Для базы больше этих пределов потребуется экспортировать данные отдельными порциями; текущий мастер этого не делает.

## 6. Запуск встроенным сервером PHP

Вместо панели Apache можно запустить `START-LOCAL.cmd`. Он найдёт PHP в `C:\xampp\php` или `XAMPP_HOME`, при необходимости запустит MariaDB и предложит:

- **1 — только этот компьютер.** Открыть `http://127.0.0.1:4173/`.
- **2 — локальная сеть.** Сайт слушает сетевой интерфейс; скрипт покажет адрес компьютера вида `http://192.168.x.x:4173/`.

Если Windows Firewall спросит доступ, разрешите его только для частных сетей. Другие устройства должны быть подключены к той же Wi-Fi/LAN сети. Для остановки сервера нажмите `Ctrl+C` в консольном окне. Не используйте встроенный PHP-сервер для публичного размещения.

## 7. Резервная копия и обновление

- Запустите `BACKUP-LOCAL.cmd` перед обновлением или переносом базы. SQL-файл будет создан в закрытой папке `storage\backups\`.
- При обновлении кода не заменяйте `app\config.php`, `storage\uploads\`, `storage\imports\` и `storage\backups\`.
- При запуске через `START-LOCAL.cmd` существующая база проходит безопасную подготовку схемы `CREATE TABLE IF NOT EXISTS`.
- При работе через XAMPP Apache запустите из командной строки `php maintenance\upgrade.php` из корня сайта после распаковки обновления.

## Установка в локальной сети из Apache

При запуске Apache через XAMPP сайт уже доступен другим устройствам по IPv4-адресу сервера, например `http://192.168.1.25/klimaeco/`. Узнайте адрес компьютера командой `ipconfig`. Если страница не открывается, разрешите Apache в брандмауэре Windows для частной сети и проверьте, что устройства находятся в одной подсети.

## Размещение на PHP-хостинге

Загрузите содержимое архива в каталог сайта, создайте базу MySQL в панели хостинга и откройте `/install/`. Укажите выданные хостингом имя базы, пользователя, пароль и адрес сайта. После установки удалите папку `install`. Не оставляйте публичный пароль MySQL пустым; скачанные экспорты и SQL-резервные копии не должны лежать в открытом веб-каталоге.

## Если установщик сообщает об ошибке

- **Красный пункт PDO MySQL или zlib:** включите расширение в `php.ini` используемого PHP и перезапустите Apache.
- **Не подключается к MySQL:** проверьте, что MySQL запущен, порт верный, база существует и у пользователя есть права.
- **Нет прав на папку:** разрешите PHP записывать в `app`, `storage/uploads`, `storage/imports` и `storage/backups`.
- **Не загружается экспорт:** проверьте точное имя файла и что он лежит непосредственно в `storage/imports`.
- **Пустая страница или ошибка PHP:** откройте журнал Apache/PHP в XAMPP Control Panel и убедитесь, что выбрана версия PHP 8.1+.

## О границах переноса

Anvil и PHP используют разные модели приложения. Мигратор сохраняет исходные записи всех 44 таблиц и переносит основные данные в рабочие разделы PHP: категории, бренды, товары, формулы, CMS-страницы, новости, галерею, проекты, помещения, системы, расчёты и сметы. Контакты заказчика и адрес объекта отображаются в карточке проекта; полные CRM-записи, строки смет, компоненты и связи систем остаются в зеркале `anvil_export_rows`, где они редактируются без потери исходных полей. Секреты, пароли и права Anvil не становятся настройками PHP автоматически.
