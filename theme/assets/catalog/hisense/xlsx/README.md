# Hisense XLSX image library

Источник: `HISENSE_прайс-лист_с_15.09.2026.xlsx`.

В исходной книге найдено **183 уникальных встроенных изображения**. Папка предназначена для GitHub-hosted файлов, которые Anvil сможет отдавать через raw HTTPS URL.

Подготовлены:
- `server_code/HisenseXlsxImageIndex.py` — связь моделей с изображениями;
- `tools/extract_hisense_catalog_images.py` — извлечение всех изображений из XLSX;
- `image_manifest.json` — контрольный индекс исходной книги после извлечения.

Видео в каталог не подключаются.
