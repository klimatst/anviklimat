# KlimaEco — Git-синхронизация для XAMPP и Anvil (Windows)

## Важное различие

- Anvil Runtime — полноценное приложение и его серверная логика.
- XAMPP/PHP — отдельный пакет из папки shared_hosting_php; он не становится автоматически полным Anvil-приложением.
- local-site на порту 4174 — облегчённый просмотр интерфейса. Он синхронизирует GitHub в отдельную папку local-site/sync-source. Это не рабочая копия репозитория и не двусторонняя синхронизация.

Не редактируйте local-site/sync-source: сервер может обновлять её из GitHub.

## Первичная проверка

Откройте PowerShell в корне клона klimatst/anviklimat — там, где находится anvil.yaml:

```powershell
git status --short --branch
git remote -v
.\tools\klimaeco-xampp-sync.ps1 -Mode Status
```

Если есть изменённые файлы, сначала сохраните их отдельным коммитом или сделайте резервную копию. Скрипт не удаляет, не stash-ит и не перезаписывает незакоммиченные изменения.

## Рекомендуемый рабочий цикл

1. Для работы на ПК создайте рабочую ветку: `git switch -c codex/xampp-work`.
2. После изменения файлов сохраните только нужные пути:
   ```powershell
   git add <нужные-файлы>
   git commit -m "Describe KlimaEco change"
   ```
3. Отправьте рабочую ветку: ` .\tools\klimaeco-xampp-sync.ps1 -Mode Push`.
4. Создайте Pull Request в GitHub и объединяйте после проверок. Не отправляйте незавершённые изменения напрямую в master.

## Режимы скрипта

- Status — только диагностика.
- Pull — получает обновления текущей ветки только fast-forward; требует чистого рабочего дерева.
- Push — отправляет уже созданные коммиты только из рабочей ветки; блокирует master и main.
- Watch — проверяет GitHub каждые 10 секунд, получает обновления при чистом рабочем дереве и отправляет уже закоммиченные изменения из рабочей ветки. Незакоммиченные файлы не публикуются. При конфликте автоматическое слияние не выполняется.

Запуск:
```powershell
.\tools\klimaeco-xampp-sync.ps1 -Mode Watch
```
Остановить: Ctrl+C.

## Запуск в XAMPP

PHP-пакет находится в shared_hosting_php. Настройте Apache DocumentRoot/виртуальный хост XAMPP на соответствующую папку согласно структуре проекта. Не открывайте административные страницы в публичную сеть до проверки авторизации, прав, секретов и защиты загрузок.

Если PHP CLI доступен, проверьте синтаксис из корня репозитория:
```powershell
Get-ChildItem .\shared_hosting_php -Recurse -Filter *.php |
  ForEach-Object { php -l $_.FullName }
```

Проверка синтаксиса не подтверждает корректность расчётов или production-готовность. Калькуляторы нужно отдельно проверять контрольными инженерными примерами.

## Ограничения и защита

- Скрипт не создаёт коммиты автоматически: нельзя надёжно определить, когда набор правок готов.
- Нет force-push; незакоммиченные файлы не публикуются.
- На master/main автопубликация запрещена.
- Если ветки разошлись, требуется ручное разрешение конфликта.
- Не синхронизируйте .anvil-data, .env, токены, пароли, приватные ключи, локальные заявки и дампы персональных данных.
- anvil watch — отдельный механизм Anvil; он не заменяет Git и не синхронизирует PHP-код XAMPP автоматически.

Эти файлы добавляют безопасный Git-процесс, но не подтверждают, что локальный XAMPP запущен или проверен: для этого скрипт нужно выполнить на самом компьютере.
