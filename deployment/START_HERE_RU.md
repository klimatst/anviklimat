# KlimaEco — самый простой запуск

## Запустить на Windows

**Нужно сделать только это:**

1. Скачай проект: https://github.com/klimatst/anviklimat/archive/refs/heads/master.zip
2. Распакуй архив.
3. Установи Python 3.11+ и Java 17:
   - Python: https://www.python.org/downloads/ — при установке включи **Add Python to PATH**.
   - Java: https://adoptium.net/
4. Открой папку проекта → `deployment` → `windows`.
5. Дважды нажми **START-KLIMAECO.bat**.
6. Когда в окне появится адрес, открой **http://localhost:3030**.

При первом запуске скрипт сам создаст окружение и установит нужные Python-пакеты. Не закрывай окно сервера, пока пользуешься приложением.

## Загрузить в интернет

Для полной системы нужен сервер, который запускает Anvil. Самый простой инфраструктурный путь — Anvil Cloud. Если нужен свой сервер, используй VPS с Linux и Docker. **Обычный бесплатный shared-хостинг Beget не запускает весь текущий Anvil-проект как обычную HTML/PHP-страницу.** Beget VPS подходит для этого сценария.

Инструкция для Docker/VPS: [README_RU.md](README_RU.md).

## Сделать Android-приложение

Сначала сайт должен работать в интернете по HTTPS. Потом PWA/TWA можно собрать в Android-приложение. Готовый APK не появится автоматически из локальной папки. Краткая инструкция: [android/README_RU.md](android/README_RU.md).

## Важно

- Данные локального запуска хранятся в папке `.anvil-data` — не удаляй её.
- Пока запускаешь локально, приложение доступно на этом компьютере по адресу `http://localhost:3030`.
- Для публикации в интернете сначала проверь логин, права, каталог, расчёты и резервную копию.
