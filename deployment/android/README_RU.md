# Android для KlimaEco: быстрый маршрут

## Рекомендуемый вариант: PWA → Trusted Web Activity

Это позволяет использовать существующий сайт как Android-приложение без переписывания всей системы. Сначала сайт должен стабильно работать на публичном HTTPS-домене.

### Этап 1. Подготовить веб-приложение
- Адаптировать сайт и админку под экран телефона.
- Проверить навигацию, формы, загрузку изображений, авторизацию и права.
- Опубликовать manifest, иконки и (при необходимости) service worker.
- Шаблоны лежат в `../pwa-template/`. Они пока не подключены к маршрутам Anvil автоматически. Не регистрируйте service worker, пока не проверите реальные URL и кеширование.

### Этап 2. Сгенерировать Android-проект
Установите Node.js LTS, Android SDK/Build Tools и Java JDK. Затем:
```bash
npm install -g @bubblewrap/cli
bubblewrap init --manifest https://YOUR-DOMAIN/manifest.webmanifest
bubblewrap build
```
Замените `YOUR-DOMAIN` на реальный домен. Команды интерактивные: укажите package ID вроде `ru.klimaeco.app` только если он свободен и принадлежит вам. Не используйте этот пример без проверки.

### Этап 3. Проверка домена (Digital Asset Links)
TWA требует файл:
`https://YOUR-DOMAIN/.well-known/assetlinks.json`

В нём должны быть package name и SHA-256 сертификата **того ключа, которым подписан APK/AAB**. Получите fingerprint у Bubblewrap/Android tooling и подставьте реальные значения. Не публикуйте шаблон с пустыми значениями. Если файл не совпадает с подписью, Android покажет интерфейс браузера вокруг сайта.

### Этап 4. Тест и публикация
- Установите собранный APK на реальное устройство.
- Проверьте вход/выход, все роли, формы, калькуляторы, каталог, загрузку фото и поведение при потере сети.
- Для Google Play следуйте актуальным требованиям Play Console и собирайте AAB; настройте безопасное хранение ключа подписи.
- Храните ключи подписи и пароли вне GitHub.

## Что не происходит автоматически
- PWA не делает весь сайт доступным офлайн.
- TWA не является нативной реализацией бизнес-логики.
- Шаблон manifest/service worker не подключён к текущим Anvil-маршрутам автоматически.
- Для push-уведомлений, Bluetooth, камеры, фоновых задач или глубокого офлайн-режима может понадобиться дополнительная разработка либо отдельный Flutter/Kotlin клиент.

Bubblewrap: https://github.com/GoogleChromeLabs/bubblewrap
