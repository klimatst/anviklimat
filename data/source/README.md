Поместите сюда исходный файл Hisense XLSX.

Workflow .github/workflows/sync-hisense-xlsx-images.yml автоматически:
1. находит XLSX;
2. извлекает все встроенные изображения;
3. сохраняет их в theme/assets/catalog/hisense/xlsx/;
4. включает библиотеку для каталога Anvil.

Видео из XLSX не подключаются.
