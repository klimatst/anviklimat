# Локальная версия сайта без Anvil

Эта папка запускает самостоятельный сайт на вашем компьютере. Для просмотра не нужны Anvil, PHP, MySQL или Docker. Локальный сервер раз в 10 секунд проверяет ветку GitHub, загружает новые коммиты в отдельную копию и обновляет открытую страницу.

## Быстрый запуск

1. Откройте папку `local-site`.
2. Дважды щёлкните `START-LOCAL.cmd`.
3. Оставьте открытым появившееся чёрное окно.
4. Перейдите в браузере по адресу `http://localhost:4173`.

Чтобы остановить сайт, вернитесь в чёрное окно и нажмите `Ctrl+C`.

## Что можно менять

- `public/index.html` — общая структура страницы;
- `public/app.js` — страницы, каталог, карточки товаров, калькулятор и локальная форма заявки;
- `public/local.css` — дополнения к стилям;
- `../shared_hosting_php/assets/style.css` — основной дизайн;
- `../shared_hosting_php/assets/images/` — изображения;
- `../shared_hosting_php/data/demo_catalog.json` — демонстрационные товары;
- `../shared_hosting_php/data/categories.json` — разделы каталога.

После изменения файлов обновите страницу браузера клавишей `Ctrl+R`. При изменении `server.mjs` остановите сервер (`Ctrl+C`) и запустите его снова.

## Локальные данные

Заявки из формы сохраняются только на этом компьютере в `local-site/data/leads.json`. Этот файл не добавлен в Git и не публикуется сам по себе.

## GitHub

Чтобы увидеть изменения из GitHub, отредактируйте файлы в GitHub и нажмите Commit changes в ветке `master`. Локальный сервер проверяет GitHub каждые 10 секунд, получает новый коммит, и открытая страница сама перезагружается. Проверьте статус и время последнего получения по адресу `http://localhost:4173/api/sync`.

Локальные изменения не отправляются в GitHub автоматически. Когда потребуется опубликовать их, используйте:

```powershell
git status
git add local-site
git commit -m "Add standalone local site"
git push
```

Перед `git push` один раз войдите в свой GitHub-аккаунт через Git Credential Manager, когда Git запросит авторизацию.

Если GitHub обновляет те же файлы, которые вы параллельно редактируете локально, сохраните локальную копию перед синхронизацией. Заявки остаются в `local-site/data/leads.json` и не переносятся в GitHub.
