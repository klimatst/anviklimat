# Локальный просмотр KlimaEco без Anvil

Эта папка запускает отдельную браузерную версию сайта из репозитория. Она нужна для быстрого просмотра интерфейса на компьютере, без Anvil, PHP, MySQL или Docker.

> Важно: это облегчённая версия для просмотра, а не полный запуск Anvil-приложения. В ней есть главная, демонстрационный каталог, карточка товара, упрощённый калькулятор и локальная форма заявки. Админка, CRM, Anvil Data Tables, инженерные модули и серверная бизнес-логика оригинального Anvil-приложения здесь не запускаются.

## Быстрый запуск Windows

1. Установите Node.js LTS: https://nodejs.org/
2. Установите Git for Windows: https://git-scm.com/download/win — он нужен для автоматической синхронизации с GitHub.
3. Дважды нажмите `START-LOCAL.cmd`.
4. Скрипт сам откроет браузер на http://localhost:4173. Не закрывайте чёрное окно, пока пользуетесь сайтом.

При первом старте сервер автоматически загружает отдельную копию публичного репозитория `klimatst/anviklimat`. Если GitHub или интернет временно недоступны, локальный просмотр всё равно попробует работать с файлами рядом с `local-site`; синхронизация будет отмечена как ошибка.

Чтобы остановить сервер, вернитесь в чёрное окно и нажмите `Ctrl+C`.

## Автоматическая синхронизация

Сервер проверяет ветку `master` примерно каждые 10 секунд. Когда появляется новый коммит, он обновляет отдельную копию и перезагружает открытую страницу.

- Статус синхронизации: http://localhost:4173/api/sync
- Сайт слушает только локальный компьютер (`127.0.0.1`), не публикуется в интернет.
- Синхронизация идёт только из GitHub в локальную копию. Изменения, сделанные на локальном компьютере, не отправляются в GitHub автоматически.
- Не редактируйте файлы внутри `local-site/sync-source`: эта папка предназначена для синхронизации.

## Какие файлы отвечают за интерфейс

- `public/index.html` — каркас страницы и навигация;
- `public/app.js` — страницы, поиск каталога, карточки, демонстрационный калькулятор и локальная форма заявки;
- `public/local.css` — стили локального интерфейса;
- `../shared_hosting_php/assets/style.css` — базовая тема;
- `../shared_hosting_php/assets/images/` — изображения;
- `../shared_hosting_php/data/demo_catalog.json` — демонстрационные товары;
- `../shared_hosting_php/data/categories.json` — категории.

После изменения файлов в GitHub нажмите Commit changes в ветке `master`; локальная копия обновится автоматически. При изменении `server.mjs` остановите сервер и запустите `START-LOCAL.cmd) заново.

## Локальные заявки и приватность

Заявки из формы записываются в `local-site/data/leads.json` только на этом компьютере. Этот файл и папка синхронизации исключены из Git. Не удаляйте `data/leads.json`, если хотите сохранить локальные заявки.

Для полноценной работы сайта, админки, прав доступа, CRM, инженерных расчётов и Anvil Data Tables запускайте оригинальное приложение через Anvil Runtime/Anvil Cloud по инструкции в `../deployment/README_RU.md`.
